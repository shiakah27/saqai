# العتاد والتوصيل والحماية

## ESP32 #1 — عقدة الحساسات (كل الحساسات هنا)

| القطعة | الطرف | ESP32 | ملاحظة |
|---|---|---|---|
| BME280 | VIN / GND | 3V3 / GND | |
| BME280 | SDA / SCL | GPIO21 / GPIO22 | العنوان 0x76، أو 0x77 إذا كان SDO موصولًا بـ VCC |
| لوحة المطر MH-RD | طرفا اللوحة | الموديول (+ و −) | سلكان بأي اتجاه، اللوحة نفسها ما لها قطبية |
| موديول المطر (LM393) | VCC | **3V3** | **ليس 5V**: مع 5V يخرج AO حتى 5V ويتلف طرف ESP32 |
| موديول المطر | GND | GND | |
| موديول المطر | AO | GPIO35 | تماثلي، ADC1. ينخفض كلما زاد الماء |
| موديول المطر | DO | GPIO16 | رقمي: LOW = مبلل (يضيء LED الموديول) |
| مقاومة 100kΩ | بين AO وGND | | يُنصح بها: لو انفصل سلك AO تُقرأ 0 = "مطر"، فيتوقف الري (آمن) |
| حساس التربة 1 (AOUT) | | GPIO32 | **ADC1 فقط**: أطراف ADC2 لا تعمل مع Wi-Fi |
| حساس التربة 2 (AOUT) | | GPIO33 | |
| حساس التربة 3 (AOUT) | | GPIO34 | |
| VCC / GND حساسات التربة | | 3V3 / GND | |

- **لوحة المطر MH-RD**: خطوط نحاسية مكشوفة؛ الماء يوصل بينها فينخفض جهد AO. ثبّت اللوحة **مائلة قليلًا (≈15°)** في مكان مكشوف، حتى ينزل الماء عنها وتجف بعد المطر بدل أن يتجمع. للعرض: رشّة ماء على اللوحة، ثم منديل لتجفيفها.
- **الموديول بعيد عن الماء**: اللوحة وحدها تتبلل؛ الموديول الصغير (فيه LM393 والبرغي الأزرق) يكون في العلبة مع ESP32، ويوصل للوحة بسلكين.
- **البرغي الأزرق** يضبط متى يصبح DO "مبلل". الكود يعتمد أساسًا على AO (بالمعايرة)، وDO تأكيد إضافي: يكفي أن يرى أحدهما ماءً. اضبط البرغي بحيث يضيء LED الموديول عند وضع قطرتين على اللوحة.
- **التآكل**: التيار المستمر على لوحة مبللة يأكل النحاس مع الوقت (أسابيع). للمعرض لا مشكلة؛ للاستخدام الطويل تُغذّى اللوحة فقط وقت القراءة، أو تُستخدم لوحة مطلية بالنيكل.
- **لا توجد حالة "الحساس لا يرد"** كما في الحساسات الرقمية: لذلك المقاومة 100kΩ بين AO وGND مهمة. بدونها، لو انفصل سلك AO يطفو الطرف ويعطي قراءات عشوائية. معها، الانفصال = قراءة 0 = "مطر" = إيقاف الري.
- **أسلاك حساسات التربة تماثلية**: كلما طالت التقطت تشويشًا. أبقيها قصيرة قدر الإمكان، أو اجدلي سلك الإشارة مع الأرضي (Twisted pair)، وأبعديها عن أسلاك المضخة والصمامات. الكود يأخذ متوسط 16 قراءة، ويعتبر أي قيمة خارج 300..3800 حساسًا مفصولًا (`valid=false`).
- BME280 داخل علبة مغلقة يقرأ حرارة ورطوبة غير صحيحة. ضعيه في مكان مظلل فيه تهوية.

## ESP32 #2 — عقدة التشغيل (مرحلات فقط، لا حساسات)

| القطعة | ESP32 | ملاحظة |
|---|---|---|
| Relay IN1 → المضخة | GPIO22 | |
| Relay IN2 → صمام المنطقة 1 | GPIO21 | |
| Relay IN3 → صمام المنطقة 2 | GPIO19 | |
| Relay IN4 → صمام المنطقة 3 | GPIO4 | |

GPIO22/21/19/4 ليست Strapping pins (0 و2 و5 و12 و15)، فلا تتحرك المرحلات عند الإقلاع. وتعمل مع Wi-Fi لأنها مخارج رقمية (قيد ADC2 يخص القراءة التماثلية فقط). GPIO21/22 مستخدمة للـBME280 على ESP32 #1 فقط، وهنا لوحة أخرى. والكود يضبط كل المخارج على OFF قبل تحويلها إلى Output.
**صمام واحد فقط يُفتح في أي لحظة**: الكود يغلق كل شيء قبل فتح صمام جديد، ومحرك القرار يختار منطقة واحدة.

## Relay module

```
         ┌──────────── مصدر خارجي 12V (أو 5V حسب المضخة) ─────────────┐
         │                                                           │
   (+) ──┴── فيوز ── COM ┐                                             │
                         ├── NO ──── (+) المضخة (-) ───────────────────┘ (-)
                         └── NC   (غير موصول: الوضع الطبيعي = مفصول)
```

- **COM**: الطرف المشترك، يدخل فيه خط الموجب من المصدر.
- **NO (Normally Open)**: مفصول وقت الراحة، ويتصل عند تفعيل المرحل. **نستخدمه دائمًا**، لأن انقطاع كهرباء ESP32 أو تعطله يعني أن المضخة والصمامات تُفصل تلقائيًا (Fail-safe).
- **NC (Normally Closed)**: متصل وقت الراحة. لا نستخدمه، لأنه يشغّل المضخة لو مات ESP32.
- **Relay input**: معظم وحدات المرحلات الزرقاء Active LOW وتحتاج نحو 15–20 mA. إشارة ESP32 بـ3.3V تكفي غالبًا للوحدات التي فيها Optocoupler أو ترانزستور. إذا لم يتحرك المرحل، استخدمي وحدة مكتوب عليها "3.3V compatible" أو "high/low level trigger". الإعداد في الكود: `RELAY_ACTIVE_LOW`.
- **VCC/JD-VCC**: إذا كان في الوحدة جمبر JD-VCC، أزيليه وغذّي ملفات المرحلات من 5V منفصلة لعزل كامل عن ESP32.

## الطاقة والحماية

| الخطر | الحماية |
|---|---|
| تشغيل المضخة أو الصمام من GPIO مباشرة | ممنوع. أقصى تيار GPIO حوالي 40 mA، والمضخة تسحب مئات الـmA أو أكثر. دائمًا عبر Relay. |
| Back EMF من ملف الصمام أو موتور المضخة عند الفصل | **Flyback diode** (1N4007 أو 1N5819) بالتوازي مع كل صمام ومع المضخة (DC)، الكاثود (الشريط) على الموجب. يحمي نقاط المرحل ويقلل التشويش الذي يعيد تشغيل ESP32. |
| Startup current للمضخة (2–5 أضعاف تيار التشغيل) | مصدر خارجي يتحمل ذروة التشغيل، ومرحل Contact rating أعلى منها بهامش (مثلًا 10A @ 30VDC للمرحلات الشائعة). |
| تيار الصمامات | صمام 12V يسحب عادة 0.3–0.6 A. لا يعمل إلا صمام واحد مع المضخة في نفس الوقت، فالمصدر يكفيه: تيار المضخة + صمام واحد + 30%. |
| قصر أو عطل في خط المضخة | **Fuse** على خط الموجب الخارجي، أعلى قليلًا من تيار التشغيل الطبيعي (مثلًا 2A لمضخة 1A). |
| تشويش من المحركات يعيد تشغيل ESP32 | مصدر ESP32 منفصل (USB أو منظم 5V مستقل). **Common ground** فقط إذا كان المرحل بلا Optocoupler. مع Optocoupler وJD-VCC منفصل، الأرضي منفصل تمامًا. |
| خطر على اللابتوب | لا توصلي الـ12V بأي شيء متصل بـUSB اللابتوب. أي خطأ في الأرضي المشترك مع 12V قد يرجع على منفذ USB. للعرض: ESP32 #2 على Power bank، والـ12V من مصدره فقط. |
| ماء قرب الكهرباء | الدوائر والمرحلات في علبة بعيدة عن خط الماء، والأسلاك من تحت. |

## الطبقات المستقلة للسلامة

1. **العتاد**: NO contacts + فيوز + دايود.
2. **ESP32 #2**: حد تشغيل محلي 60 ثانية، وإيقاف إذا انقطع الـBackend 3 ثوانٍ أو صارت الحساسات قديمة، وإيقاف فوري عند المطر، والمضخة تُطفأ قبل الصمام دائمًا.
3. **الـBackend**: RAIN_LOCKOUT، ويرفض بدء أي تشغيل أثناء القفل (RUN_REFUSED)، وتشغيل نشط واحد فقط (قيد في قاعدة البيانات)، والأوامر اليدوية لها command_id وexpires_at.
4. **الذكاء الاصطناعي**: لا يلمس أيًا مما سبق. يعطي احتمالًا فقط، ومحرك القرار يستخدمه للتأجيل فقط.

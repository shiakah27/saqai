## 3. اختبار الأمان طرف-لطرف (36 فحصًا ✅)

Backend حقيقي + PostgreSQL + خدمة الذكاء + **محرك القرار الحقيقي بلغة C++** (عبر `esp32/tests/decide_cli`).
يعمل على **قاعدة بيانات اختبار منفصلة** (اسمها فيه `test`) لأنه يمسح القراءات؛ ويرفض العمل غير ذلك.

```bash
# مرة واحدة
docker compose exec db createdb -U saqai saqai_test

# نافذة 1: Backend اختبار على منفذ آخر (خدمة الذكاء تعمل على 8000)
cd backend
PORT=3100 NODE_ENV=test ALLOW_DEVICE_TIMESTAMPS=true DATABASE_URL=postgresql://saqai:<pass>@localhost:5432/saqai_test \
  RAIN_COOLDOWN_MINUTES=0.25 SOAK_SECONDS=5 SENSOR_STALE_SECONDS=4 npm start

# نافذة 2
SAQAI_URL=http://localhost:3100 DATABASE_URL=postgresql://saqai:<pass>@localhost:5432/saqai_test \
  RAIN_COOLDOWN_MINUTES=0.25 npm run e2e
```

| المرحلة | ما يُفحص |
|---|---|
| التحقق من المدخلات | بلا مفتاح 401، ضغط بالباسكال 400، حقل ناقص 400، نوع خاطئ 400، جهاز غير مسجل 403، عقدة الحساسات لا تنتحل عقدة التشغيل 403، منطقة غير موجودة 422، `RAIN_STARTED` مع `rain_detected=false` 400، تقرير انتهاء والمضخة ON 400، رطوبة مستحيلة تُخزن غير صالحة |
| التنبؤ | تنبؤ من تاريخ المحطة نفسها |
| القرار | المنطقة 1 (20%) → `CRITICAL_DRY`، المنطقة 3 (26%) → IRRIGATE لكن تنتظر دورها، المنطقة 2 (45%) → SKIP، **منطقة واحدة مختارة (الأحوج)**، المضخة ON والصمام 1 فقط مفتوح، القرار مخزن مع trace |
| المطر أثناء الري | الحدث → RAIN_LOCKOUT، الاستعلام التالي يوقف (يُقاس بالـms)، التشغيل CANCELLED/RAIN_OVERRIDE، كل المناطق HOLD، بدء تشغيل أثناء القفل مرفوض، الأمر اليدوي 409، سلسلة الأحداث كاملة |
| بعد المطر | COOLDOWN → HOLD، ثم NORMAL، القرار بقراءة التربة الجديدة ويختار منطقة واحدة، تشغيل جديد بـrun_id جديد، التقرير المكرر بلا أثر، التسرب بعد النبضة (الحلقة المغلقة) |
| الأوامر اليدوية | تصل لعقدة التشغيل بـcommand_id، وتُنفذ مرة واحدة فقط |
| انقطاع عقدة الحساسات | الحساسات قديمة → عقدة التشغيل توقف كل المناطق `INPUTS_STALE` |

## 5. على العتاد 🔧

| الحالة | كيف | المتوقع |
|---|---|---|
| قراءات لحظية | افتحي اللوحة وانفخي على BME280 أو امسكي حساس التربة | الأرقام تتغير خلال ثانيتين، الشارة "مباشر" |
| صمام واحد فقط | جففي حساسين (أخرجيهما من التربة بعد المعايرة) | تُروى الأجف فقط، والأخرى "ينتظر دوره"، ثم تأخذ دورها بعد التسرب |
| الوصول للهدف | ضعي الحساس في كوب ماء أثناء الري | توقف `TARGET_REACHED` |
| مطر أثناء الري | رشّ لوحة المطر | المضخة OFF خلال 3–5 ث، اللوحة "قفل المطر" |
| Wi-Fi ينقطع أثناء الري | أطفئي الـHotspot | المضخة OFF خلال ≈3 ث، تقرير `BACKEND_UNREACHABLE` عند العودة |
| عقدة الحساسات تنطفئ | افصلي كهرباء ESP32 #1 أثناء الري | توقف `SENSORS_STALE` خلال ≈10 ث |
| لوحة المطر مفصولة | افصل سلك AO (مع مقاومة 100kΩ) | خلال 3–5 ث قفل المطر (الخيار الآمن)، وتنبيه `AO reads ~0` على Serial |
| حساس تربة مفصول | افصلي AOUT | `SENSOR_INVALID` لتلك المنطقة فقط |
| BME280 مفصول | افصلي SDA | لا إطارات → الحساسات قديمة → لا ري |
| حد التشغيل المحلي | ضعي `MAX_PUMP_ON_SECONDS=120` في backend/.env وشغّلي اختبارًا يدويًا 90 ث | ESP32 يوقف عند 60 ث بنفسه (`LOCAL_MAX_ON_TIME`) |
| إقلاع | أعيدي تشغيل ESP32 #2 | لا يتحرك أي مرحل |
